# Batalla de Genios

| Ficha | |
|-------|---|
| Estado | movida |
| Plataforma candidata | Game Boy |
| Origen | Prototipo propio en Godot 4.6 |
| Año | 2026 (según las fechas de los archivos, mayo de 2026) |

Juego de puzle: rellenar un tablero de 6×6 con 9 piezas, esquivando 7 casillas bloqueadas que cambian en cada partida.

Ya se desarrolla en el repo [gameboy](https://github.com/Manzupas/gameboy):

- Versión de Game Boy: [juegos/batalla-genios/](https://github.com/Manzupas/gameboy/tree/main/juegos/batalla-genios)
- Versión original de Godot, archivada: [archivo/godot/](https://github.com/Manzupas/gameboy/tree/main/archivo/godot)
